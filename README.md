#Bank ATM Simulation System Using Python

About the Project

This project is a simple ATM simulation system developed using Python. It provides a menu-driven interface that allows users to perform basic banking operations.

Features

- Cash Withdrawal
- Cash Deposit
- Balance Enquiry
- Change ATM PIN
- Exit with confirmation

Concepts Used

- Python Variables
- User Input and Type Conversion
- Functions
- If-elif-else Statements
- While Loops
- Global Variables

Technology Used

- Python
- Jupyter Notebook

Purpose

The purpose of this project is to practise Python programming concepts by developing a basic real-world banking application.

Note: This is an educational simulation and is not connected to any real banking system.
